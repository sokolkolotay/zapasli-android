# Zapasli Android

Android-клиент сервиса совместного учёта домашних продуктов.

## Текущий статус

Завершён первый полноценный offline-сценарий приложения. Пользователь может просматривать кладовую, фильтровать продукты по сроку годности, добавлять, редактировать и удалять позиции. Данные сохраняются локально в Room и остаются после перезапуска приложения. Для продукта поддерживаются количество, место хранения, штрихкод, срок годности и КБЖУ.

Добавлено сканирование потребительских штрихкодов EAN/UPC через собственный CameraX-интерфейс и встроенную модель ML Kit. После распознавания приложение выполняет read-only запрос к Open Food Facts API v3.6 и заполняет доступные название и КБЖУ, не перезаписывая уже введённые пользователем значения. При отсутствии камеры, разрешения, сети или продукта в каталоге остаётся ручной ввод.

Android-клиент подключён к собственному production API по HTTPS: доступны регистрация, вход, восстановление сессии с ротацией refresh-токена и выход. Токены шифруются AES-GCM ключом из Android Keystore, исключены из backup и не выводятся в логи. После успешного входа локальная кладовая остаётся доступна без сети; приложение явно отмечает offline-сессию.

Для каждого push и pull request настроена автоматическая проверка сборки, unit-тестов, instrumented-test APK и Android Lint. Пользовательский offline-путь дополнительно проверяется на Android-эмуляторе.

## Технологии

- Kotlin, Jetpack Compose, Material 3
- Hilt, Room, DataStore, KSP
- CameraX, ML Kit Barcode Scanning
- Retrofit, OkHttp, Kotlin Serialization, Open Food Facts API v3.6
- Android Gradle Plugin 9.3.2, Gradle 9.5.0
- compileSdk / targetSdk 37, minSdk 26
- Application ID: `ru.zapasli.app`

## Локальный запуск

1. Откройте каталог в Android Studio.
2. Дождитесь Gradle Sync.
3. Запустите конфигурацию `app` на эмуляторе или устройстве с Android 8.0+.

Проверка из терминала Windows:

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

Проверка Room и полного пользовательского сценария на запущенном эмуляторе:

```powershell
.\gradlew.bat connectedDebugAndroidTest
```

## Архитектура

- `domain/pantry` — модели и контракт кладовой.
- `core/database` — локальная Room-база и DAO.
- `data/pantry` — offline-реализация репозитория.
- `core/preferences` — только несекретные настройки интерфейса в DataStore.
- `ui/pantry` — экран кладовой, форма продукта, состояние UI и ViewModel.
- `domain/catalog` и `data/catalog` — контракт и реализация поиска продукта.
- `ui/scanner` — CameraX-превью, scanner UI и локальное распознавание.
- `domain/auth`, `data/auth` и `ui/auth` — контракт, HTTPS API, защищённая сессия и UI авторизации.

Правила работы с ключами, токенами и уязвимостями описаны в `SECURITY.md`.

## Источник данных

Название и КБЖУ продукта могут загружаться из [Open Food Facts](https://world.openfoodfacts.org/). База Open Food Facts распространяется по лицензии Open Database License (ODbL); Zapasli явно указывает источник полученных данных. Ответы каталога используются для автозаполнения формы и должны проверяться пользователем.
