# Zapasli Android

Android-клиент сервиса совместного учёта домашних продуктов.

## Текущий статус

Создан foundation-проект: настроены Jetpack Compose, Navigation 3, светлая и тёмная темы, фирменная палитра, типографика Onest и первый демонстрационный экран. Для каждого push и pull request настроена автоматическая проверка сборки, unit-тестов и Android Lint.

## Технологии

- Kotlin, Jetpack Compose, Material 3
- Android Gradle Plugin 9.3.2, Gradle 9.5.0
- compileSdk / targetSdk 37, minSdk 26
- Application ID: `ru.zapasli.app`

## Локальный запуск

1. Откройте каталог в Android Studio.
2. Дождитесь Gradle Sync.
3. Запустите конфигурацию `app` на эмуляторе или устройстве с Android 8.0+.

Проверка из терминала Windows:

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

## Ближайшие этапы

1. Базовая архитектура приложения и внедрение зависимостей.
2. Локальное хранение кладовой и пользовательских настроек.
3. Авторизация, семейная синхронизация и собственный backend API.
4. Сканирование штрихкодов и чеков.
5. КБЖУ, персональные цели питания и рекомендации блюд.

Продуктовая и техническая документация находится в соседнем каталоге `ZapasliDocum`. Репозиторий задания Netology используется только как источник требований и не изменяется.
