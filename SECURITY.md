# Security Policy

## Защита данных

- Секреты backend, ключи подписи, токены и локальные конфигурации не хранятся в Git.
- В `DataStore` допускаются только несекретные пользовательские настройки.
- Авторизационные данные должны храниться с использованием Android Keystore и добавляются только вместе с backend-аутентификацией.
- Мобильный клиент не должен содержать серверные секреты: всё, что включено в APK, считается доступным пользователю.
- Распознавание штрихкода выполняется встроенной моделью ML Kit на устройстве; кадры камеры не сохраняются и не отправляются в сеть.
- Запросы к каталогу продуктов выполняются только по HTTPS и содержат только отсканированный штрихкод. Интеграция Open Food Facts read-only и не требует пользовательских учётных данных или API-ключа.

## Сообщение об уязвимости

Не публикуйте секреты или сведения об уязвимости в обычном Issue. Используйте приватную форму **Security → Report a vulnerability** в репозитории GitHub.
